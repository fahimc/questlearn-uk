# Curriculum-to-game matrix

The matrix identifies where a mechanic produces useful evidence. A theme alone is not integration: putting an arithmetic question on a castle door is practice, while calculating a bridge span and testing whether the build works is application.

| Learning family | Blocksmith Worlds | Skybound Academy | Chronicle Keepers | Evidence captured |
|---|---|---|---|---|
| Number and operations | Resource quantities, arrays, budgets, scale | Short fluency route locks | Codes and inventory totals | Answer, method model, latency band, hint |
| Fractions/decimals | Partition plots, recipes, material ratios | Equivalent-fraction route choice | Reconstruct page portions | Representation used, equivalence transfer |
| Measure/geometry | Perimeter, area, coordinates, angles, conversion | Position, turns, timing, coordinates | Map scale and chronology line | Build validity, estimate vs result |
| Reading comprehension | Interpret build briefs and evidence cards | Parse concise instructions | Core loop: inference, retrieval, summary, vocabulary | Selected evidence, confidence, explanation |
| Writing | Labelled plans and design rationale | End-of-run reflection | Restore and compose passages for audience | Rubric dimensions; teacher review needed |
| Working scientifically | Design fair tests in simulated habitats/materials | Predict and observe forces | Evaluate claims from evidence | Variable choice, observation, claim/evidence link |
| Computing | Build automation using sequences/loops/variables | Debug movement routes | Logic and source-evaluation puzzles | Program execution, debugging edits |
| Geography | Biomes, settlement, maps, resources and fieldwork imports | Navigate coordinates and terrain | Compare place accounts/maps | Map task, justified location decision |
| History | Reconstruct settlements with source constraints | Chronology routes | Core loop: sources, interpretations, narratives | Source selection and justification |
| Design & technology | Core loop: research, prototype, test, improve | Design safer obstacle sequences | Book/object restoration projects | Iteration history and criteria evaluation |

## Recommended first content packs

1. **Year 3 settlement builder:** multiplication arrays, perimeter, plants, rocks, maps and Stone Age-to-Iron-Age evidence.
2. **Year 4 river habitat:** tables to 12 × 12, area, states of matter, habitats, rivers and settlement.
3. **Year 5 expedition archive:** fractions/decimals/percentages, forces, Earth and space, map scales, historical sources and upper-KS2 comprehension.

## Interaction budget

Aim for 70% meaningful play/application, 20% embedded retrieval or deliberate practice and 10% reflection/choice. This is a design hypothesis to test with children and teachers, not a research-derived universal ratio.

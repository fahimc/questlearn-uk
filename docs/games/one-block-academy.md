# One Block Academy

## Game promise

Start with one renewable block in the sky. Mine it, solve a curriculum challenge, unlock a new resource phase and build a larger island from everything collected.

This is an original EduGames browser game inspired by the general one-block sky-survival genre. It reuses Blocksmith's voxel scale, procedural textures, first-person building language, curriculum adapters, local/private save boundary and low-power device policy.

## Run structure

- Years: 3, 4 and 5.
- Subjects: English, maths and science.
- Ten phases per expedition.
- One non-repeating question at each phase gate; two questions from every Level 1–5.
- Ten adjacent expedition sets exhaust the selected 100-question year/subject scope without repetition.
- After phase ten, the renewable block enters an unlimited mixed-resource mode. The learner can keep building or begin the next question set.

## Interaction

- Desktop: WASD/arrows, mouse look, left-click Mine, right-click Place, Space Jump, number keys for the hotbar and Escape Pause.
- Touch: independent analogue stick, drag-to-look world, Mine, Place and Jump buttons, plus a block inventory drawer.
- Mining the renewable centre block grants its visible material and immediately replaces it.
- Placing consumes one owned block and snaps to the voxel grid.
- Falling into the void respawns the player on the centre block and preserves the island, inventory, phase and learning progress.

## Educational gate

The block locks at the end of each phase. A compact dialog shows the scoped question and two block answers. Learn and Hint are optional. Correct answers grant a resource cache and unlock the next phase; incorrect answers keep the same gate open with neutral retry feedback.

## Safety and storage

There are no adverts, chats, public profiles, purchases or loot boxes. The scoped run and player-built island are stored only in the browser on that device.

# Game design plans

All three concepts use the same learning contract and UI library but create different evidence:

- [Blocksmith Worlds](blocksmith-worlds.md): 3D creative construction and simulation.
- [Skybound Academy](skybound-academy.md): 3D obstacle-platforming and short retrieval/application.
- [LexiClimb Tower](wordwall-tower.md): 3D tower parkour with spelling, vocabulary and grammar gates.

These are original educational designs inspired by broad genres—not copies of particular worlds, art, names, levels or code.

## Portfolio roles

| Game | Primary motivation | Best learning mode | Session | Production engine candidate |
|---|---|---|---|---|
| Blocksmith | creativity/ownership | application, modelling, design | 15–25 min | Babylon.js |
| Skybound | movement/mastery | fluent retrieval, quick reasoning | 5–10 min | Babylon.js |
| LexiClimb | movement/mastery | spelling, vocabulary, grammar | 10–15 min | Three.js |

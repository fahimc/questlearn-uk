# Game design plans

All four concepts use the same learning contract and UI library but create different evidence:

- [Blocksmith Worlds](blocksmith-worlds.md): 3D creative construction and simulation.
- [Skybound Academy](skybound-academy.md): 3D glass-bridge platforming with Year 3–5 and English/Maths/Science selection, ten physical answer bridges and non-repeating routes from the shared [900-question bank](curriculum-question-bank.md).
- [LexiClimb Tower](wordwall-tower.md): 3D rainbow-circuit parkour with Year 3–5 selection, five levels, five one-question walls per level and varied stair, tunnel, slope, donut and ribbon paths in separate Maths, Science and English worlds, backed by a [900-question year-tailored bank](curriculum-question-bank.md).
- [Maths Outbreak](maths-outbreak.md): child-friendly first-person swarm action where learners solve an equation, tag exactly that many blocky zombies, confirm the count and reach the next checkpoint.

These are original educational designs inspired by broad genres—not copies of particular worlds, art, names, levels or code.

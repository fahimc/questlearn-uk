# Earlier concept: Chronicle Keepers

Chronicle Keepers is retained as an earlier narrative prototype. LexiClimb Tower is the active third EduGames plan and homepage game.

## Promise

Stories are disappearing from a magical archive. Explore illustrated 2D worlds, restore missing language and decide which evidence belongs in the record.

## Core loop

`Explore scene → discover fragment → read/listen → infer/classify/order → see story consequence → collect relic → reflect`.

Choices change scene details or routes but do not use false moral labels. The system can explain why evidence supports an inference and lets the learner revise.

## Learning integration

- close reading: retrieval, inference, prediction, summary, themes and authorial language;
- vocabulary, morphology, conjunctions, sentence cohesion and punctuation;
- history: chronology, source reliability, similarity/difference and interpretations;
- science/geography: evaluate claims using evidence, classify, compare maps/accounts;
- writing: assemble a paragraph for purpose/audience, with teacher-reviewed rubric evidence.

## Accessibility

Readable text width, dyslexia-friendly spacing option, narrated text with word highlighting, captions, pause anywhere and no speed pressure. Images support rather than replace essential information. Learners can respond through choice, ordering or structured sentence tiles before extended typing.

## Content episode model

Each episode has 3 scenes, 5–7 learning encounters, one transfer task and a recap. Content authors provide passage rights/licence, reading demand, vocabulary, objective mapping, misconception feedback, audio script and cultural/sensitivity review.

## MVP

One chapter, four English/history encounters, five relics, local save and responsive DOM interaction. Prototype: [`site/games/chronicle.html`](../../site/games/chronicle.html).

## Risks and tests

- **Reading load blocks the objective:** readability review and narration/segment variants.
- **One “correct” interpretation:** accept evidence-backed alternatives where appropriate; author rubrics.
- **Story reward distracts from explanation:** require brief evidence selection before consequence.
- **Cultural flattening:** named expert reviewers and provenance for historical content.
